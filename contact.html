The fastest way to report a bug or suggest a correction is through the public GitHub issue tracker for this project.

Open GitHub Issues ↗

Useful bug reports include

  • The conversion you selected, such as HEIC → JPG or PDF → PNG.
  • The browser and device you used.
  • The file type and approximate file size.
  • The exact error message or what happened instead of the expected download.

Privacy note

Please do not attach private or sensitive documents to a public issue. Describe the problem without sharing personal files whenever possible.
