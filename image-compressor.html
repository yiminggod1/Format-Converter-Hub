What does image compression do?

Compression removes or repacks image data so a file can use less storage or transfer less data. Quality, dimensions, and output format all affect the final size.

When should you compress an image?

Compress before publishing to a website, uploading to a form with a size limit, emailing a batch of photos, or preparing assets for a faster page.

Practical defaults

  • Start around 80–90% quality for JPG or WebP.
  • Resize only when the destination does not need the original dimensions.
  • Keep originals for archival or editing workflows.

Frequently asked questions

Does compression always make an image smaller?

Not always. PNG can remain similar in size or even grow after recompression. The tool reports the actual result for each file so you can keep only changes that help.

Are images uploaded?

The compression workflow runs in your browser. The original image is not sent to a conversion server by this page.
