DATA GUIDE

CSV vs JSON
for moving data.

CSV is naturally tabular and easy to open in spreadsheets. JSON works especially well for APIs, application data, and nested structures.

Use CSV for tables

CSV maps naturally to rows and columns, which makes it convenient for reports, spreadsheet workflows, exports, and simple datasets.

Use JSON for structured application data

JSON can represent nested objects and arrays and is common in web applications and APIs.

Conversion tips

When converting JSON to CSV, nested values need a representation inside a cell. When converting CSV to JSON, check headers carefully because they become object keys.
