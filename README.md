# Format Converter Hub

A browser-first file conversion platform focused on useful high-intent conversion workflows rather than a generic list of buttons.

## Working conversion tools

- JPG / PNG / WEBP conversion
- HEIC to JPG / PNG
- AVIF to JPG / PNG / WEBP routes supported by the browser decoder
- SVG to PNG
- TIFF to JPG / PNG / WEBP where the decoder can read the source
- JPG / PNG to PDF
- PDF to JPG / PNG
- JSON to CSV
- CSV to JSON
- Image compression with quality and dimension controls
- Batch file processing and drag-and-drop upload

## Search-intent pages

Important conversion routes have dedicated static pages with format-specific explanations, practical guidance, FAQs, structured data, canonical URLs and related navigation. The current cluster includes image, PDF, data and compression intents.

## Privacy model

Supported conversion workflows are designed around client-side processing. The original file is not sent to a conversion server by the browser-side tools described as local.

Third-party browser libraries may be loaded from public CDNs to provide format decoding or PDF rendering.

## Quality and safety

The project deliberately marks unsupported routes as unavailable instead of claiming that every format pair works. Automated QA checks JavaScript syntax, required assets, sitemap entries and key engine references on every push.

## Monetization

Advertisement positions are reserved in the layout. Connect Google AdSense only after the domain, publisher ID, consent/privacy configuration, substantial original content and final manual review are ready.
