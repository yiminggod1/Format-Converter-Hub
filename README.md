# Format Converter Hub

A browser-first file conversion platform focused on high-intent format-to-format searches.

## Working in the first release
- JPG / PNG / WEBP conversion
- GIF / BMP conversion where the browser can decode the source
- JSON to CSV
- CSV to JSON
- Drag-and-drop upload
- Responsive UI
- Format directory and conversion guide sections

## Product strategy
The site will expand around individual conversion intents such as HEIC to JPG, WEBP to JPG, SVG to PNG, JSON to CSV and CSV to JSON. Each important conversion should eventually have a dedicated static SEO page with original explanations, examples, FAQ and related conversions.

Unsupported routes are deliberately labelled as planned instead of pretending every button already works.

## Privacy
Supported conversions run locally in the browser. The site does not upload those files to a conversion server.

## Monetization
Advertisement slots are reserved in the layout but should only be connected to AdSense after the site has substantial original content, clear navigation, privacy/legal pages and stable functionality.
