Why convert PDF to WEBP?

WEBP is designed for efficient web images. Rendering selected PDF pages as WEBP can reduce image transfer size compared with some older formats while keeping the page as an image.

How to convert PDF to WEBP

Choose PDF as the source, choose WEBP as the target, select one or more files, then let the browser build the output. For image-to-PDF workflows, multiple selected images can become one PDF with one image per page.

Good to know

  • Multiple files can be selected.
  • Page order follows selection order.
  • PDF pages use an A4 layout with margins.
